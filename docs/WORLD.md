# 세계관과 용어 — Contour Cut

사용자가 승인한 공식 세계관 초안(DECISIONS P-006). 게임 화면에 쓰는 이름과 이야기 설정의 기준 문서다.
정하지 않은 것은 "미확정"으로 남기고, 이 문서에 없는 설정을 화면이나 코드에 새로 만들지 않는다.

## 대접힘 (The Folding)

공간 구조가 붕괴하면서 세계가 등고선 단위로 찢겨 나갔다. 고도가 낮은 영역은 물질과 정보가 소실되는 **절대 심연(Zero Datum)** 으로 가라앉고, 인류는 단애와 메사 위에 위태롭게 정착해 살아간다.

- "Zero Datum"은 측량학 용어(기준면 0)를 게임 세계에서 의도적으로 재해석한 고유명사다.

## 주인공 — 카인 (The Black Cartographer)

- 전직 군사 측량 장교이자 공인 측량사.
- 공간의 등고선을 시각화하고 절단하는 장비 **측량도(Contour Cutter)** 를 쓴다.
- 목표: 붕괴 이전의 기준면을 복원하기 위해 세계의 중심에 있는 **원점 타워(Benchmark Zero)** 로 향한다.

## 적대 세력

- 붕괴한 고지대를 점유하고 지형 복구를 방해하는 무장 세력과 왜곡 방위대.
- **미확정**: 이들이 왜 지형 복구에 반대하는가(생존을 위한 저항인지, 세계를 붕괴시키려는 것인지 등). 향후 서사에서 결정한다. 그 전까지 화면 문구는 동기를 암시하지 않는다.
- 현재 프로토타입의 적 두 종(붉은 사냥개형 돌진, 보라 삼각점형 사격)이 어느 세력에 속하는지도 미확정이다.

## 용어

| 세계관 용어 | 영문 | 게임 규칙에서의 뜻 |
|---|---|---|
| 측량 절단 | Survey Cut | 일반 공격. 칼날로 등고선을 벤다 |
| 단층 침하 | Fault Subsidence | 벤 등고선 안쪽 고지대가 내려앉는 것 |
| 지형 환원 | Restoration | 침하한 땅이 일정 시간 뒤 원래 표고로 돌아오는 것 |
| 절대 심연 | Zero Datum | 표고 0 아래로 떨어진 낙하 소멸 영역 |
| 표고 | Elevation | 고도 |

## 화면 반영 범위 (PR #2, 2026-10-14)

익숙한 조작 안내와 기능 이해를 해치지 않는 곳만 바꿨다. 기술 코드 식별자·주석은 바꾸지 않는다(예: `cut`, `restoreSec`, `ABYSS`).

| 위치 | 반영 | 바꾸지 않은 것과 이유 |
|---|---|---|
| 타이틀 | 한 줄 소개: 대접힘, 검은 측량사 카인, 원점 타워 | 게임 제목·조작 버튼 문구 |
| HUD 처치 수 | "심연" → "절대 심연", 에어본 수 추가 | "지형 처치·칼날", "WAVE" — 짧고 익숙함 |
| 알림 | "절대 심연 추락", "지형 환원 — 에어본", "공중 추가타" | "낙하 처치", "충격파" |
| 도움말(H) | 측량 절단·단층 침하·지형 환원·절대 심연·표고를 뜻과 함께 | 키 이름, "이동·대시·조준" |
| 튜닝 패널(T) | 침하 낙차·침하 반경·환원 시간 | 나머지 조정값 이름 |
| 게임 오버 | 측량 절단 n회, 침하시킨 칸 | "측량 중단" 제목은 원래 있던 것 |
| 쿨다운 막대 | "칼날" → "절단" | — |

## 향후 서사에서 정할 것

- 적대 세력의 동기, 적 두 종의 소속과 이름
- 카인의 과거(군 측량 장교 시절), 원점 타워까지의 여정 구성
- 측량도의 능력 확장(예: 등고선 폐곡선 절단 — DECISIONS P-008)
