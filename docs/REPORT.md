## 실행 검증 ①: 실행한 경로, 결과, 보존한 재현 조건
- 계기(`?scenario=cut`): 준비(램프 켜짐) → 빈 땅 절단 → 재충전(램프 꺼짐·라벨 보조색) → 준비 → P 일시정지(두 트랙 해칭·램프 꺼짐) → P 해제. 실험 시나리오는 우상단 "실험: cut", 구역 블록 숨김
- 계기(`?scenario=swarm`): 체력 1에서 체력 칸·라벨 레드, 잃은 칸 4 → 게임 오버에서 계기 사용 불가, 잃은 칸 5
- 가림 윤곽(`?scenario=hidden`): 메사 윗면이 덮은 돌진형·사격형 몸 위치에 각 색 픽셀(캔버스에서 직접 셈), 같은 높이의 빈 메사 위에는 0
- DPR 1.25(1536×740)·1.5(1280×600)·2(1280×720): 캔버스 폭 = 480의 정수배 = 표시 기기 픽셀 폭, 왼쪽·위 끝이 기기 픽셀 경계, HUD 기하 통과, 출발 자리에서 측량 1 대지를 실제 클릭으로 베어 절대 심연 처치. 1.25는 이전 배치에서 실패하는 경우(캔버스 1440 ↔ 표시 1200), 1.5·2는 회귀 방지
- 기존 경로(첫 여정 완주·구역 2 다리·구역 3 단독·리뷰 재현·게임 오버·도중 R·잘못된 주소·무한 웨이브·실험 시나리오 전부) 새 HUD 단언으로 통과
- 재현 조건: `npm test`, `npm run e2e`
