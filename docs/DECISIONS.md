## 기술 결정 (AI 위임)

### T-001 스택: TypeScript + Vite + Canvas 2D, 게임 엔진 없음 — 2026-10-14
- 이유: 필요한 것은 격자 높이 데이터, 2.5D 그리기, 키보드·마우스 입력뿐이다. 엔진 없이 파일 몇 개로 끝나고, 규칙을 순수 함수로 두면 Vitest로 결정적 시험이 된다. 브라우저라 사용자가 설치 없이 실행하고, Playwright로 실제 입력→화면 검증을 CI까지 돌릴 수 있다.

### T-014 2.5D 가림 윤곽 — 2026-10-14
- 줄 단위로 그리는 2.5D(T-003)에서는 남쪽(앞쪽) 높은 지형이 뒤의 엔티티를 덮는다. 다 그린 뒤, 적·플레이어 스프라이트의 1px 테두리 픽셀 중 지형이 덮은 것에만 그 엔티티 색(돌진형 빨강·사격형 보라·플레이어 시안)을 다시 찍는다. 보이는 부분은 그대로라 평소 화면은 변하지 않는다.
- 가림 판정은 조준이 쓰는 `terrainCoversAfterRow`(input.ts)를 그대로 쓴다. 조준·판정은 바꾸지 않는다(가려진 적은 지금처럼 커서로 잡히지 않음 — PR #2 리뷰로 고친 조준 규칙 보존).
- 테두리 픽셀은 스프라이트를 32×32 캔버스에 한 번 그려 알파로 구해 종류·좌우별로 캐시.
- 확인용 실험 시나리오 `hidden` 추가(실험실 메사 바로 북쪽에 멈춘 적 둘). 기존 시나리오는 그대로.
- 거부한 대안: 가려진 엔티티 전체를 반투명으로 위에 다시 그리기(지형이 엔티티 위에 떠 보여 2.5D 깊이가 무너짐), 높은 지형을 반투명으로(지형 읽기가 흐려짐), 조준에서도 가려진 적 잡기(입력 규칙 변경 — 별도 결정).

### T-015 기기 픽셀 기준 정수 배율 — 2026-10-14
- 이전: CSS 정수 배율 s, 캔버스 배율 ceil(s·DPR). DPR이 정수가 아니면(125%) 캔버스 1440px를 1200 기기 px에 그려 픽셀 폭이 고르지 않았다(UI System 07 "렌더러 과제").
- 이후: k = floor(min(창 기기 폭/480, 창 기기 높이/270)), 캔버스 480·k, CSS 크기 480·k/DPR, 위치도 기기 픽셀 경계(floor). HUD 단위 `--s` = k/DPR. DPR 1에서는 이전과 같다. DPR 2 등에서는 게임 화면이 창을 더 크게 채울 수 있다. 캔버스 배율 상한 8(그 이상은 k의 약수로 그리고 정수배 확대). DPR 변화(확대 비율·모니터 이동)는 resize와 `matchMedia(resolution)`으로 다시 맞춘다.
- 조준·관찰 좌표는 모두 `getBoundingClientRect` 기준이라 그대로 맞는다(e2e: DPR 1.25·1.5·2에서 실제 클릭 절단).

### T-019 공중 추가타의 시각 계층, 공간·분위기 — 2026-10-14

- 지평선: 지도 윗변 위로 접힌 단애 실루엣 두 겹과 원점 타워(Benchmark Zero, 점멸등). 장면 비네트(가장자리 최대 30%).
- 구역 공기: 균열 지대 = 심연에서 오르는 불티, 접힘 협곡 = 동쪽으로 부는 먼지, 환원 구역 = 떠오르는 시안 입자(1px, 옅게). 무한 웨이브·실험은 회색 먼지.
- 거부한 대안: 무작위 장식 소품 배치(공간 구조와 무관한 잡음), 비네트 50%(가장자리의 카인이 어두워짐 — 캡처로 확인 후 30%로).

### T-020 소리 2차: 균형·공기·반복 피로 — 2026-10-14
- 검증 방법: 개발 서버의 실제 `src/audio.ts`를 OfflineAudioContext에 연결(`Sfx.attach`)해 핵심 연쇄와 혼잡 시험을 렌더링하고 파형을 쟀다(커밋하지 않는 스크립트). 듣기 품질은 판단하지 않았다.
- 측정으로 고친 것: 공중 추가타(보상)가 일반 절단보다 작았음 → 공중 추가타가 가장 크게(최대 0.55), 처치 0.18 → 0.45, 대시가 공기 소리에 묻힘 → 키움, 침하 둔음 줄임. 혼잡 시험(1초에 절단+침하 12번·공중 추가타 6번) 최대 0.60, 클리핑 0, 사건 시작 지연 8~12ms.
- 구역 공기(아주 작은 지속음): 균열 = 낮은 울림·바스락, 협곡 = 오르내리는 바람, 환원 = 옅은 맑은 떨림. 일시정지 0.4·쓰러짐/돌파 0.25로 줄이고, 피격 순간 잠깐 눌린다. 자주 나는 소리(절단·타격·처치·대시·발사)는 음높이 ±3% 흔들림. 피격에 낮은 둔음(공격 성공과 구분), 쓰러짐 소리.

### T-021 체감 품질 3차: 구역 재질, 진입 측량, 절단 미리보기 — 2026-10-15 (사용자 요청 "환경 완성도와 첫 여정 고도화", 연출·UX 위임)
- 진단(같은 실제 입력의 전후 캡처): ① 세 구역이 같은 남색 바닥에 등고선 배치만 달라 장소로 느껴지지 않음, 구역 1 첫 화면에 "붕괴한 세계·심연"의 인상이 없음 ② 어느 땅이 무너질지는 베어 봐야 앎(규칙 학습이 시행착오), 직접 타격과 지형 처치의 차이가 클릭 전에 안 보임 ③ 진입은 가운데 글자 배너뿐 ④ 게임 오버에 쓰러진 까닭이 없음.
- 구역 재질(`src/theme.ts`, 그리기 전용): 구역마다 지면 색 계단·절벽면·서쪽 빛 그림자 길이와, 땅에 붙어 함께 오르내리는 표면 무늬. 무늬는 원래 지형(base)으로 정해져 무너진 땅도 제 무늬를 지닌 채 내려앉는다. 균열 지대 = 잿빛 현무암, 불씨가 숨쉬는 비스듬한 균열(등고선과 헷갈리지 않게 어둡고 옅게), 가장자리가 어두워지는 지도, 부서진 지평선과 떠 있는 바위. 접힘 협곡 = 깊은 바닥은 차갑게 어둡고 높은 단은 사암, 절벽면 지층 띠, 몇 칸 너머까지 드리우는 단애 그림자, 바닥·균열 위로 흐르는 점묘 안개, 계단식 단애 지평선. 환원 구역 = 청록 광물, 언덕·환원대를 둘러싼 동심 고리(땅의 기억)가 바깥으로 차례로 밝아지는 파동, 꼭대기의 측량 기준점, 절벽면 시안 광맥. 무한 웨이브·실험은 이전 화면 그대로. 심연 가장자리에서는 흙 부스러기가 이따금 떨어진다(균열 지대는 더 자주). 타이틀 뒤의 지도도 첫 구역 재질.
- 진입 측량: 구역에 처음 들어설 때 진입 방향(구역 1·3 남쪽, 구역 2 서쪽 단애)에서 측량 주사선이 1.15초 동안 지도를 그려 나간다(앞쪽은 어두운 청사진 모눈, 주사선 바로 뒤 등고선은 흰색). 배너는 지도 표제란(도면 번호 · 구역 이름 · 목표 · 표고 범위 · 진입 방향 · 전술). R로 다시 할 때는 이전처럼 짧은 측량 신호와 이름 한 줄 + "다시 측량"(1.3초). 둘 다 입력·시뮬레이션을 막지 않고(e2e로 확인), 연출 줄이기면 주사선을 생략한다.
- 절단 미리보기: 절단이 준비되어 있고 칼날 선이 등고선을 지나면, 지금 베면 내려앉을 칸을 빗금과 흐르는 점선 테두리로 보인다(흰색 = 침하, 적색 = 절대 심연). 계산은 실제 절단과 같은 `Terrain.previewCut`(cut이 이 함수를 쓴다 — 단위 테스트로 같은 칸을 고정, e2e로 "보인 그대로 심연"). 그 위의 적 머리 위에 운명 화살(적색 두 겹 = 심연, 주황 두 겹 = 낙하로 쓰러짐, 주황 한 겹 = 낙하 피해), 내 발밑이 심연이 되면 카인 머리 위에 적색 화살이 깜빡인다(알려 둔 함정 T-009·T-011을 클릭 전에 보이게). 곧 솟는 땅(환원 경고 시간 + 0.4초) 위의 적에게는 위를 가리키는 시안 화살(에어본·공중 추가타 기회). 판정·조준·규칙은 그대로.
- 첫 절단 안내: 단계 데이터의 `focus`(구역 1 첫 측량 대지·포대 메사, 구역 3 가두기 언덕·가운데 환원대) — 그 단계에서 처음 벨 때까지 그곳 등고선이 흰색으로 깜빡인다. 문구는 늘리지 않았다.
- 실패 원인: 다침 사건에 까닭(돌진·탄·심연)을 싣고, 방금(1.5초 안) 무너진 칸에 빠졌으면 "내가 벤 발밑"으로 구분한다. 게임 오버 화면 첫 줄에 까닭과 다음 시도에 쓸 한 줄, 알림 줄도 "발밑이 무너짐"으로 구분.
- 성능: 표면 무늬는 바닥·높은 땅 무늬를 칸 모양으로 오려 한 장으로 미리 합성하고(시간 변화는 장 교체), 줄마다 합성한 띠를 그 줄의 높이·무늬 장·안개 위치가 바뀔 때만 다시 만든다. 읽어 들인(getImageData) 캔버스는 새 캔버스로 옮겨 소프트웨어 그리기 전환을 피한다. 개발 서버, 1280×720, 같은 기계 측정에서 메인 스레드 사용률 구역 1·3은 이전과 비슷(+1~3%p), 구역 2는 +7~9%p(안개·지층) — 모두 60fps 유지.
- 거부한 대안: 조명 덧칠을 장면 전체에(적·카인 색까지 물들어 가독성 하락 — 빛은 땅 무늬에만 구움), 무작위 장식 소품(T-019와 같은 이유), 진입 컷신·입력 잠금(반복 플레이 지연), 힌트 문구 추가(지형 강조·미리보기로 대신), 미리보기를 항상 표시(조준·절단 준비 상태일 때만 — 정보는 필요한 순간에만).
