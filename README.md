# Contour Cut — 등고선 절단기

2D 평면 지도의 등고선을 베어 3차원 공간의 높낮이를 왜곡하는 탑다운 액션 게임의 **프로토타입**.
목표는 하나: "등고선을 베면 지형과 전투가 바뀐다"는 경험이 실제로 재미있는지 확인하는 것.

> 대접힘 이후 세계는 등고선 단위로 찢겨 나갔다. 검은 측량사 카인은 측량도로 등고선을 베며 원점 타워로 향한다.
> 세계관과 용어: [docs/WORLD.md](docs/WORLD.md)

## 실행 방법

필요한 것: [Node.js](https://nodejs.org/) 24 이상(한 번만 설치).

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 <http://127.0.0.1:5173> 을 연다. 타이틀에서 **첫 여정 시작**(기본) 또는 **무한 웨이브**를 고른다.

배포용 빌드로 실행하려면 `npm run build` 후 `npm run preview`(<http://127.0.0.1:4173>).

## 첫 여정

세 구역을 차례로 돌파한다. 구역 1은 절단과 낙하, 구역 2는 고도차 이동, 구역 3은 시간차 지형 조작과 콤보를 익힌다. 구역마다 체력 5로 시작하고, 쓰러지거나 R을 누르면 그 구역을 처음부터 다시 한다.

| 구역 | 목표 | 플레이 경로(예) |
|---|---|---|
| 1 균열 지대 | 세 번의 측량(적 6) | ① 출발 자리에서 바로 앞 대지를 벤다 ② 동쪽 메사 남쪽에서 메사를 베고(사격형 3단 낙하), 서쪽 대지 남쪽에서 대지를 벤다 ③ 북쪽 둔덕 고리 안으로 들어가면 적 셋이 다가온다 — 고리를 넘는 적의 발밑을 벤다. 돌파 화면에 측량 평가(S·A·B) |
| 2 접힘 협곡 | 동쪽 출구 표지(노란 고리)까지 돌파. 적을 다 잡을 필요는 없다 | 세 구간(HUD에 구간 이름과 힌트). ① 단애: 끝에서 대시하면 협곡 바닥을 넘어 활강, 걸어 내려가면 착지 충격파로 바닥의 돌진형 기절. 바닥의 균열 웅덩이(영구 심연)는 대시로만 건넌다 ② 사격 회랑: 남북 능선의 사격형 — 기둥 뒤가 엄폐, 능선 가장자리를 베면 사격형이 떨어진다 ③ 심연 균열(폭 9칸): 계단으로 도약대(표고 4)에 올라 대시해 활강하거나, 남쪽 다리를 걸어 건너 광장으로 2단 내려서며 충격파(다리는 한 방향 — 광장의 적은 올라오지 못한다). 평지에서 대시하면 못 건너고 빠진다 |
| 3 환원 구역 | 세 번의 환원(적 3 → 5 → 6) | 평평한 바닥(표고 1)에는 등고선이 없어 베어도 무너지지 않는다 — 언덕과 환원대(표고 4의 탁자)를 쓴다. ① 가두기: 북쪽 언덕 바깥을 베어 감시자 둘을 구덩이에 가두고, 동쪽에서 오는 돌진형을 상대하다가 7초 뒤 떠오른 감시자를 벤다 ② 환원대: 서·동쪽 끝과 북쪽에서 오는 돌진형 넷 + 동쪽 언덕 사격형. 환원대를 베면 바닥 높이가 되고, 그 위에 적을 끌어들이면 7초 뒤 솟는 땅이 한꺼번에 띄운다 ③ 대환원: 서쪽·북쪽 언덕 사격형 + 남쪽 돌진형 넷. 콤보는 유리할 뿐 강제가 아니다(칼날·낙하로도 정리 가능) |

구역을 돌파하면 결과 화면(다음 구역의 전술 한 줄 포함)이 나오고 Enter(또는 버튼)로 다음 구역으로 간다. 세 구역을 마치면 "첫 여정 완료"(환원 구역의 에어본·공중 추가타·공중 처치 따로 표시). 특정 구역부터 하려면 `/?zone=2`처럼 붙인다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동. 1단 턱은 오르고, 2단 이상 절벽은 못 오른다. 내리막은 그냥 뛰어내린다 |
| 마우스 | 조준. 칼날이 닿을 선(점선)과 그 선이 벨 등고선(깜빡이는 십자)이 보인다 |
| 왼쪽 클릭 / J | **측량 절단**(등고선을 벤다) |
| Space / Shift / K | 대시(이동 방향, 멈춰 있으면 조준 방향). 대시 중 무적 |
| 오른쪽 클릭 | 조준 방향으로 대시 |
| R / N | 다시 시작(첫 여정: 이 구역 처음부터, 완료 뒤: 여정 처음부터) / 새 지도(무한 웨이브만) |
| Enter | 구역 돌파 화면에서 다음 구역 |
| P / Esc | 일시정지 |
| H / T / M | 도움말 / 튜닝 패널 / 소리 끄기 |

## 규칙 (프로토타입)

- **측량 절단 → 단층 침하**: 칼날이 지나간 등고선마다, 그 선이 둘러싼 고지대가 반경 6칸 안에서 3단 내려앉는다. 표고 2 이하였던 땅은 **절대 심연**이 된다.
- **지형 환원 → 에어본**: 무너진 땅은 7초 뒤 원래 표고로 돌아온다(직전에 깜빡인다). 그 위에 있던 적은 공중으로 튕겨 올라 잠시 무방비가 된다(머리 위 마름모). 이때 베면 **공중 추가타**(2 피해). 환원 자체는 피해를 주지 않는다.
- **적 낙하**: 발밑이 무너진 적은 그대로 떨어진다. 2단 이상 떨어지면 피해(낙차 − 1)와 기절, 심연이면 즉사. 칼날 직접 타격은 1 피해뿐이다.
- **이동 방해**: 적은 고도차 1까지만 걷는다. 계단식 언덕의 안쪽을 베면 꼭대기가 2단 벽에 둘러싸인 구덩이가 되어 적이 갇힌다.
- **지형 이동**: 내려서면 낙차만큼 잠깐 빨라진다. 2단 이상 뛰어내려 착지하면 충격파가 주변 적을 기절시키고 밀쳐 낸다(밀려서 절벽 아래로 떨어지기도 한다). 대시로 뛰어내리면 활강해 멀리 간다.
- **회피**: 사격형(보라 삼각점)의 탄은 쏜 자리보다 높은 지형에 막힌다. 높은 곳이 엄폐물이다. 반대로 높은 곳의 사격형은 고지대 가장자리를 벗어난 탄을 아래로 내려 쏜다.
- 적: 붉은 주름 사냥개(접근해 돌진, 체력 3), 보라 삼각점(조준 후 사격, 체력 2). 기본 전장은 웨이브마다 적이 늘어난다.

수치는 T키 튜닝 패널에서 바로 바꿔 볼 수 있다(새로고침하면 기본값).

**전투 HUD**(UI System v0.1 1단계): 좌상단 구역 블록(구역 · 지금 단계와 목표 수치 · 진행 눈금 — 끝난 단계 초록, 지금 단계 시안), 좌하단 계기(체력 칸, 절단 오렌지·대시 시안 게이지 — 램프가 켜지면 준비, 일시정지 중 사선), 위 가운데 알림(색 = 원인: 지형 처치 오렌지, 환원·공중 시안, 내 위험 레드), 아래 가운데 힌트. 처치 통계는 전투 중에는 숨기고 구역 돌파·게임 오버 화면에서 본다. 높은 지형 뒤에 가려진 적·플레이어는 가려진 부분만 윤곽으로 보인다. 화면은 기기 픽셀 기준 정수 배율로 그려 Windows 배율 125% 등에서도 픽셀이 고르다.

**지형 표현**: 높을수록 밝고 그 고도 등고선 색을 띤 땅(단채), 지층선이 보이는 절벽면과 그늘, 5칸마다 측량 눈금(+). 벤 땅은 원래 등고선을 원래 높이에 점선으로 남기고, 환원이 다가올수록 점선 → 파선 → 실선으로 차오르다 직전에 시안으로 깜빡인다. 돌진형은 돌진할 길을 붉은 점선으로 예고하고, 사격형 조준선은 발사 직전 적색이 된다.

**움직임과 공간**: 카인은 걷기·숨쉬기·기울기·외투 자락·착지 눌림·측량도 휘두르기·쓰러짐 동작이 있고, 사냥개는 돌진 전에 웅크리고 떨며, 삼각점은 렌즈가 붉어지며 쏜다. 공중 추가타 순간에는 장면이 한 박자 어두워지며 맞은 적만 남는다. 지평선 너머 원점 타워, 구역마다 다른 공기(불티·바람 먼지·시안 입자)와 공기 소리.

**연출과 접근성**: 강한 타격(처치·공중 추가타·2단 이상 착지)에 짧은 멈춤(60ms)과 순간 줌인, 고지대에서 대시로 뛰어내리면 미세한 줌아웃. T키 패널의 "연출 줄이기"로 화면 흔들림·줌을 한 번에 끄거나, 각 배율과 멈춤 시간을 따로 조절한다. 운영체제의 "동작 줄이기"가 켜져 있으면 처음부터 꺼진다(시작·재시작 때 퍼지는 측량 신호 고리도 함께 생략).

## 실험 시나리오

기능 하나씩 확인하는 고정 배치 지도. 주소 뒤에 붙인다(웨이브 없음, R로 처음부터).

| 주소 | 내용 |
|---|---|
| `/?scenario=lab` | 메사·계단 언덕·낭떠러지와 적 4마리. 자유 실험 |
| `/?scenario=fall` | 메사 위의 적을 땅째 떨어뜨리기 |
| `/?scenario=abyss` | 계단 언덕을 베어 심연 만들기 |
| `/?scenario=trap` | 언덕 꼭대기의 적을 구덩이에 가두기 |
| `/?scenario=combo` | **핵심 루프 연습**: 동쪽에서 언덕 바깥 고리를 베고 → 심연 앞까지 다가가 → 7초 뒤 튕겨 오른 적을 벤다 |
| `/?scenario=dash` | 낭떠러지에서 대시로 뛰어내려 충격파 |
| `/?scenario=cover` / `exposed` | 사격형의 탄을 높은 곳에서 피하기 / 같은 높이에서 맞기 |
| `/?scenario=highshot` | 메사 위 사격형이 아래로 내려 쏘는 탄 |
| `/?scenario=swarm` | 적 8마리에 둘러싸인 상태(게임 오버 확인용) |
| `/?scenario=hidden` | 메사 바로 북쪽(뒤)에 선 적 둘 — 높은 지형에 가려진 몸이 윤곽으로 보이는지 확인 |
